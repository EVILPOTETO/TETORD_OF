# TETORD Desktop

TETORD 2.1.1 empaquetado como aplicación de escritorio con Electron.

## Requisitos para compilar
- Windows 10/11
- Node.js LTS
- npm

## Ejecutar en desarrollo
```bash
npm install
npm start
```

## Crear instalador y portable
```bash
npm install
npm run dist
```

Los resultados aparecen en `dist/`:
- `TETORD-2.1.1-x64.exe` — versión portable
- `TETORD-Setup-2.1.1-x64.exe` — instalador de Windows
